# 创作链：素材 → 观点 → 前提 → 追问

> 蒸馏自教主《人人都能学会单口喜剧》（2018，下称「书 1」）与石老板《单口喜剧表演手册》（2019 V1.1，下称「手册」）。两本书是同一套体系的两种讲法：书 1 讲「为什么」与心态，手册给可操作清单。

## 0. 学习路径总览

1. **建立认知**：看优秀专场，弄清什么是单口喜剧（推荐：George Carlin、Jerry Seinfeld、Dave Chappelle、Trevor Noah、周奇墨；纪录片《Comedian》）
2. **先报一个一周后的开放麦**——人都有惰性，没有演出逼着就永远开始不了写段子
3. **每日训练**：10 条前提 / 10 个观点，至少坚持一个月；梗概练习 + 海量输入
4. **上台验证**：素材筛选 → 观点 → 加梗 → 结构 → 排练计时
5. **循环**：录音 → 复盘八问 → 修改 → 再上台

> 教练用法：用户说「想学单口」时，把第 2 步当作第一作业布置。

## 1. 素材五原则

| 原则 | 判断标准 | 禁忌 |
|---|---|---|
| **真实** | 真实发生过，框架已搭好；见闻/感受/经历都行 | 编的东西观众听得出来，一旦质疑就不听了 |
| **个人** | 「故事里面得有你」；职业/爱好/父母/童年/感情/宠物都是矿 | 太公共的话题没有个人视角，容易撞梗 |
| **宜人** | 听众敢笑；新人少碰宗教、性、哲学 | 不是不能冒犯，是不碰「本能不敢笑」的话题 |
| **熟悉** | 有发言权、有细节支持 | 不熟悉就只能编，观众觉得不真诚 |
| **普适** | 找到「个人经历 × 观众联系」的最大公约数 | 「我很爱国」太空，「昨天吃了碗米饭」没得说 |

**操作要点**
- 「有印象的事情，就是最好的素材」——先定主题，再列有印象的事，不要一上来写段子。
- 细化主题：交通 → 地铁 → 地铁安检 → 高峰期的地铁安检。脑中要有画面。
- 共鸣分两种：**事实共鸣**（这事儿我也见过）与**情感共鸣**（太对了就是这个感觉）。生气是表象，事件背后真正的情感才共鸣。
- 共鸣会失效：自认有共鸣 ≠ 真有共鸣（当地人看的可能根本不是那个节目）——最终要靠开放麦验证。

## 2. 观点提炼

**核心公式：观点 = 事实 + 负面情绪。段子的文体是议论文，不是记叙文。**

- 万能句式：「关于＿＿（素材主题），让我觉得＿＿（负面情绪）的是，＿＿（事情概括）」。
- **常见错误**：
  - 「主题 + 情绪」≠ 观点，必须「**事情 + 情绪**」——「关于猫，让我觉得无可奈何」这样写下去是死路一条；
  - 「无可奈何 / 尴尬 / 无语」这类偷懒情绪词是思考上的偷懒；
  - 多个论点混在一起，观众必然听不明白。
- **创作顺序**：先有事情，才有观点。**不要按四个情绪去找事情**——先多找含荒诞点的事，再提炼情绪。观点可以变，一件事不一定只有一个观点。
- **议论文框架**：引子 → 论点 → 解释荒诞点 → 例子 → 分论点 → 解释荒诞点 → 例子……「有观点才能有结构，有结构才有加梗的可能性」。
- **训练纪律**：每天 10 个观点，坚持一个月；**写观点就是写观点，不加任何梗**（有趣措辞记另一个本子）。笔记本分三栏：奇思妙想（梗的前身）/ 梗概 / 观点。
- **Let it brew**：段子放一段时间会更好笑——写完先搁着，别急着定稿。

## 3. 负面情绪四角度（口诀：难怪怕蠢）

人发笑是为了缓解紧张，**只有负面情绪能引发紧张**，之后才能靠包袱释放。四角度是提炼情绪的引导工具，不必纠结归类，熟练了可以换词：

| 角度 | 自查句式 |
|---|---|
| **难**（觉得困难） | 「这就有问题了。」——描述事件后接上你觉得困难的点 |
| **怪**（觉得奇怪） | 「用来干嘛呢？」「你怎么知道的呢？」——忍不住想发问 |
| **怕**（觉得害怕） | 「我靠，这要是当时……我就……」 |
| **蠢**（觉得愚蠢） | 「这也太傻了，感觉就像……」——强制想「为什么蠢呢？」 |

- 愤怒是表象，背后一定有原因（通常指向对方「怪」或「蠢」），纯愤怒段子少。
- 情绪也可以来自别人（如「我妈是体育老师」），但初期慎用。

## 4. 前提

**铺垫 = 主题（topic）+ 态度（attitude）+ 前提（premise）。**

- 前提 = 主题里的具体观点，段子围绕它展开。态度可以不说出来，但一定存在。
- **写前提的方法**：选一个主题，用四个负面态度（困难/奇怪/害怕/愚蠢）各问一遍自己的感受，答案就是前提。公式：铺垫 = 问题（主题+态度）+ 答案（前提）。
- **前提注意事项**：
  - 写真情实感，不人云亦云；
  - 四个态度都是负面的，一定选负面；
  - 一定要多写，数量远比质量重要；
  - **前提里不出现「我 / 我们 / 我的」**——太强调个人独特信息会丢掉共鸣。（注意：进入呈现环节后可以用亲身经历支持前提。）
- **好前提的标准**：是一个原创的观察；能准确回答「关于 xx，让我觉得困难/奇怪/害怕/愚蠢的是什么」。
- **筛选五问**：足够具体清楚？原创？有态度？能引起共鸣？有没有「我、我的」？
- **日课**：每天精神最好的时候写 10 条前提。「写段子不是靠灵感，对专业演员是技术活。」

## 5. 追问法（段子伙伴的核心动作）

把一句话观点细化成多个层次：不停追问三个问题——

- **why**：为什么会有这种负面情绪 / 为什么这么说？
- **how**：怎么个难法 / 具体怎么发生的？
- **what else**：还有什么类似的事 / 别的角度？

追问出来的每一层 = 议论文里的分论点 = 段子里「细化后的观点」。

**教练用法**：模式 C 下你就是段子伙伴——连环追问，不替用户下结论；**段子伙伴觉得有问题的地方，就是观众不笑的原因**。

- 概括能力：一句话概括里埋着矛盾，故事就好看（参考《救猫咪》）。
- 段子伙伴要接受同一套方法论——今天问这个明天问那个，最后都只学了皮毛。

## 6. 荒诞性与刻意练习

- **荒诞性 ≈ 有冲突、有变化的点**。逐条为素材找冲突点，找到的才值得往下写。
- 四件刻意练习：
  1. **梗概训练**：写 10 个印象最深的故事梗概（不是完整故事），按五原则筛；
  2. **海量输入**：大量看专场、读书，边看边记录——很多人输坏在输入环节；
  3. **参加故事会**：「讲述才是一切，**讲熟之前千万别动笔写**」；
  4. **与人闲聊**：每个故事讲 5-6 遍，素材库快速变厚。
- **观点合并练习**：同主题梗概合并归纳观点；不同主题的梗概碰撞出新主题。
- **三小时金线**：人一辈子值得说的事够三小时段子——坚持积累，成熟演员手里都有三小时。
