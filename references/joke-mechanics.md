# 包袱机制与加梗六法

> 蒸馏自手册第四课（写包袱）与书 1 第四章（加梗）。所有手法都是给「观点」服务的——**真的好笑的点永远是你的观点**，加梗是辅助，不要急着加梗。

## 1. 笑的机理：预期违背

- 你笑，是因为**现在发生的事和你预判的不一样**——这种差别让紧张释放。任何一个段子都是一种预期违背。
- **段子公式**：段子 = **铺垫**（不好笑、建立预期的部分）+ **包袱**（好笑、打破预期的部分）。包袱即「梗」。
- 为什么有效：假设的紧急情况消失了，情绪得以释放（挠痒痒的机理——警觉解除）。
- **初学者先在铺垫上花更多时间**：没有真实具体的素材，包袱是空中楼阁，只能落进网络段子的俗套。
- 成熟段子必须有加梗部分；不加梗会出现「开头挺想听，后面莫名其妙」。

## 2. 铺垫 → 包袱的加工路径

把前提中的观点进行生动展示与再加工：戏剧化表演、夸张、倒错逻辑、断章取义——「源于生活高于生活」，自然超出预期。两种最基本的包袱结构：

- 结构 I：**包袱 = 呈现**
- 结构 II：**包袱 = 呈现 + 混合 + 再次呈现**

## 3. 加梗六法

### ① 呈现（act-out）

- **定义**：表演出来——举例、直接演、模仿。「**能表演的不叙述**」「你是演段子，不是念段子」。
- **万能操作**：放下笔站起来开录音，把情绪调到与前提一致，模仿对话、分饰两角，像真的在发生；回头听录音，把有趣部分记下来。
- **要领**：
  - 提到谁就演谁；说铺垫时面向观众，扮演角色时跟虚拟角色对话；
  - 呈现的情绪**与前提相同**，不继续发展；
  - 单一视角展开效果独特（只演乘客、或只演司机）；
  - 演完留几秒，让观众自己反应过来再笑。
- **禁忌**：太夸张或太传神反而不好；来回晃、眼神乱窜；事无巨细全演；为落一个谐音梗来回演七八轮。
- **适用**：情绪抽象（尴尬、无奈）时；事情本身有画面（对话有趣、动作滑稽）时。

### ② 比喻

- **万能句式**：「**xx 实在是太 xx 了，就好像……**」——后半句把注意力集中到形容词上，容易继续加梗。
- **适用**：为了让观众理解你的负面情绪而生——「观众一思考，就会忘了笑」，比喻是把观众从思考里拉回来的工具。

### ③ 类比

- **万能句式**：「**我上一次看到这样的事情，还是在……**」——短平快，适合做引入环节；讲男女差别时尤其好用。
- 类比其实已算轻度「混合」。

### ④ 夸张

- **要领**：把局部适当夸大，喜剧效果来自**不合理**——不是「快了一秒」，而是「对方八点就收到了」。夸张后顺势用具体例子说明。
- **底层原理——优越感**：「段子里得有个傻子」——让观众笑你，观众就快乐。新人多自嘲，但**不能假自嘲**（明显好看的人说「我太丑了」笑不出来）。自己优越感太强，观众会讨厌你。

### ⑤ 假设

- **动机假设**：问「他们为什么这么干？」——句式「**咋的？**」
- **后果假设**：问「这样干下去会怎么样？」——句式「**这样下去会不会……**」
- **极端假设（高阶）**：把逻辑推到极限再演出来，造成「看似很符合逻辑但完全错位」（漫才常用）。
- **纪律：假设完必须再呈现**——假设是头脑里的设想，观众理解成本太高，演出来才能减少动脑时间。

### ⑥ 混合

- **定义**：把两种不相关甚至对立的东西嫁接，产生错位喜感。
- **万能句式**：「**如果这样可以的话，那么那样是不是也可以？**」
- **四类比较角度**（可直接当练习题）：
  - 时间：古代-现代 / 结婚前-结婚后 / 过去过年-现在过年；
  - 空间：中国-外国 / 办公室-家；
  - 角色：家里的妈妈-职场里的妈妈 / 线上人格-线下人格；
  - 视角：我的视角-动物 / 我的视角-对方的视角。
- **要点**：情形越荒谬、情绪波动越大越适合混合；观点不痛不痒时硬混合=无病呻吟；整个段子态度要贯穿始终；混合之后往往接「再次呈现」把荒谬演到极致。

## 4. 组合拳与节奏

- 六法不是菜单点菜，**要融会贯通动辄组合**：呈现 × 混合、夸张 × 假设是常见搭配。
- 写完的结构只是分析工具，观众不需要知道你怎么写的——把割裂的部分糅成整体。
- 比喻/类比等解释工具的密度要克制：都在解释，观众就没有地方笑了。

## 5. CallBack（首尾呼应）

把之前出现过的句子**在结尾重新说一遍**，一般用于收尾呼应。要点：

- 呼应的句子当初必须立得住（够好笑、有记忆点）；
- 首尾之间隔得越远、语义发生变化，效果越强（同一句话在新语境里变了意思）；
- 一个 set 最多一两个 call back，多了会显得设计感过重。

## 6. 原创红线（行业底线）

- **抄段子 = 「摞叶子」**：行业会联合封杀。「抄来之前是 9 分，自己讲出来就是 5 分」——对抄来的观点没有感情，讲不好。
- **抄观点也算抄**：分论点、论证角度、思维逻辑一并搬走 = 彻底抄袭。
- **套梗（换皮）也是抄**：保留别人的梗概、例子、观点，只换成自己的梗——既不好笑又别扭。
- **公共观点的边界**：「演出观众少」「高铁小孩吵」这类公共话题可以用，但必须给出自己的新角度。
- **谐音梗**是最低层级的梗（因为最容易得到），只做锦上添花；指望谐音梗撑全场是偷懒。
