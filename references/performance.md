# 打磨、表演、开放麦与复盘

> 蒸馏自手册第五/六/七课（表演准备 / 表演 / 演出回顾）与书 1 第五章、小白的笔记、附录（演出组织规范）。

## 1. 打磨三步（没有段子是靠「重复讲」变好笑的，都是靠「改」）

1. **反复研究正确的段子与方法论**：大量看表演，可以仿风格但内容必须原创；警惕变成「资料收集狂魔」。
2. **重新提炼观点**：先搜「梗概」榨干熟悉话题；不同话题的梗概结合可能变成新观点——**重组、提炼**，像修电视一样拆开看零件，而不是使劲拍。
3. **表演**：按下面五要点执行。

### 表演五要点

| 要点 | 内容 |
|---|---|
| **精简** | 「少即是多」；**餐巾纸原则**——想法必须能写在一张餐巾纸上；凡冷场的部分都有删掉的空间 |
| **别晃** | 站稳、眼睛盯两个观众头中间的空隙；晃来自身体的逃跑机制；先练「一动不动」再练走动 |
| **投入** | 把表情、语调、动作调到段子里的情绪；**回忆起那个情绪、呆在里面直到演完** |
| **节奏** | 留白宁短勿长；铺垫两大错误——**水词太多**（对/有点儿/你知道吗）与**事无巨细**；叙事类段子=片段式，观点类=总分总；**写逐字稿、脱稿彩排**——「不能战胜书面语的人，段子一定不好笑」 |
| **熟练** | 熟练是一切表演的前提；忘词、卡壳非常不专业 |

- 双角色切换三招：对话短且关系清晰 / 用不同音调口音 / 模仿 A 朝左、模仿 B 朝右。
- 同一周的开放麦用**一模一样的讲法**（控制变量），周末听录音复盘，一周最好 ≥3 场。

## 2. 排序与准备

- **排序总原则**：最浅显直接的话题放最前；可能触犯禁忌的话题放最后；**「好-差-好-差」岔开**，最好的段子放最后——「每个演员都希望在笑声中下场」。
- 老段子-新段子-老段子-新段子；短平快放开头或过渡；**不要一上来讲长段子**。
- **过渡**：两个主题没有逻辑关系就别强行加过渡——观众不在乎主题之间是否连贯，无效过渡只会拖节奏。
- **排练**：找没人的地方**出声、加动作**地演；按「主题→段子→要点→顺序」的层级记忆；带情绪排练；**不要在镜子或镜头前练**。
- **记词**：紧张就背逐字稿；不紧张就只记每个段子的小要点，临场微调。
- **忘词救场**：直接说「哎呀我忘词了，我想说什么来着」——真实状态换来善意笑声；**别硬用段子缓尴尬**。
- **计时**：开放麦单次 4-5 分钟；「永远守时」——有 5 分钟就只安排 4 分半的段子；严重超时会被主持人直接拽下台。

## 3. 冷场五大成因与对策

冷场大部分时候原因很简单：**段子不好笑**。排除这一条后按五个成因查：

| 成因 | 对策 |
|---|---|
| **段子顺序** | 上场先用短平快让观众笑一下（调侃上一个演员/主持人/场地），建立「他懂我」 |
| **观众警惕性** | 互动的精髓**不是出梗，而是真的去了解他**；多练主持 |
| **能量差异** | 观众能量低时把自己能量降下去再逐步回升；演员能量过低观众会憋住笑 |
| **留白长短** | 别预设「爆梗时间」（多变成超级尴尬时间）；新人一直讲下去，**绝不让人看出你忘词** |
| **环境** | 仪容、场地、天气做万全准备，不找客观借口 |

心态：冷场是家常便饭；「你冷场观众不会记住」。新人不是被开头五分钟压垮的，是被连续冷场压垮的——按本表归因，改一处再上。

## 4. 开放麦纪律

- 开放麦是**工具不是表演**：测段子、练控场；不用设计「破冰+爆梗收场」的完整演出。
- **行动指令**：还没上台过的用户，第一作业永远是——先报名一个一周后的开放麦。
- 上台前：提前 15 分钟到；跟主持人打招呼；**准备好录音设备**（上台不录音=白上）。
- **千万不要带完整文本上台**——会埋头找字，逗不笑人；带一张关键词小纸条。
- **撞梗即弃**：发现前面演员讲了内容严重类似的段子，毫不犹豫换掉。
- 现场可留意明显的事（观众多少、天气）用一句陈述拉近距离，别强行抖机灵。
- 麦克风：音量先试；持麦抓中上部；动作别太大；双手动作前先把麦放回架子。
- 演后：可以问**老演员**的建议；**不要问观众要建议**（外行指导内行），但要观察观众的反馈——笑没笑、前提是否有共鸣。

## 5. 演出复盘（复盘八问）

「总结演出和演出本身同等重要。」每次录音，对照八问：

1. 是否过于冗长？
2. 是否有明确的态度？
3. 主题是否跟观众有共鸣？
4. 是否都包含呈现部分？
5. 是否把段子讲成了故事？（讲成故事=观点缺席）
6. 是否说了三句以上的话才开始抖包袱？
7. 是否给观众留出足够的反应时间？
8. 观众是否在你说出包袱之前就猜到了？

**删减原则**：某段长时间没笑声，就问「删掉它影不影响有笑声的部分」——不影响就删，**无论内容多有哲理多有用**。这是喜剧表演，不是百家讲坛。

**其他**：
- 别按思考路径叙述——你所说的一切都应为包袱服务（啰嗦是新演员第一通病）。
- 「怎么又是老段子」的真实含义：**你的段子不够好，而不是不够多**。很多演员要花几年才能磨出 15 分钟好段子。
- 五件事分开做，不来回切换：找新话题前提 / 给已有前提加呈现混合 / 排练 / 回顾 / 重审成熟段子。
- 天赋观：**天赋没那么重要**——要的是正确的方法和持之以恒的训练。无论如何不要停止上台。

## 6. 演出组织速查（运营模式 F）

| 项目 | 参数 |
|---|---|
| 单场时长 | 90 分钟左右，最长 120 分钟；开放麦演员 ≤10 人 |
| 场地 | 交通方便、相对封闭；**方形/长方形最佳**，层高 ≤3 米，容纳 30-50 人，「聚气」优先；远离吧台；不选边吃边看的圆桌 |
| 布置 | 超 20 人设 20cm 高、≥1.5㎡ 的舞台；硬质有靠背椅扇形摆放、不摆桌子；第一排距舞台约 0.8 米；话筒优先有线，无线备新电池；灯光集中舞台 |
| 宣发 | 提前两周定海报文案；注明四条：禁录音录像 / 18+ / 手机静音 / 冒犯请一笑置之 |
| 票务 | 开放麦提前半月、商演提前 10 天、专场提前一个月开票；赠票 ≤20%；商演到场率 ≥ 最佳容量的 70% |
| 演员 | 新老搭配、风格搭配；新人 ≤5 分钟、老演员 ≤10 分钟；**须提前备稿，禁止无准备即兴**；严禁抄袭 |
| 现场 | 开场声明禁录像；**计时员在结束前两分钟晃手机提示**；过场音乐卡演员结束的瞬间响起 |
| 分工 | 制作人 / 现场导演 / 报幕 / 引座 / 检票 / 计时 / 过场音乐 |
| 演后 | 引导关注、搜反馈、发总结；财务 1-2 个工作日结算 |
